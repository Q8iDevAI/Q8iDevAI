تطبيق Q8iDevAI هو عميل لوكلاء الذكاء الاصطناعي للبرمجة الذين يعملون على جهازك الخاص. بيئة تطويرك بالكامل في جيبك.

يعمل Q8iDevAI كخادم محلي يُسمى الـ daemon على حاسوبك، ويدير وكلاء البرمجة ويبث مخرجاتهم في الوقت الفعلي. يتصل هذا التطبيق بذلك الخادم، بحيث لا تغادر شفرتك البرمجية جهازك أبداً ولا توجد أي خدمة سحابية وسيطة.

<b>الوكلاء المدعومون</b>

<ul>
<li>Claude Code</li>
<li>Codex</li>
<li>GitHub Copilot</li>
<li>OpenCode</li>
<li>Pi</li>
</ul>

تستخدم بيانات الاعتماد واشتراكاتك الحالية الخاصة بك. لا يفرض Q8iDevAI أي تكاليف إضافية أو رسوم استدلال خاصة به.

<b>ما يمكنك فعله</b>

<ul>
<li>تشغيل الوكلاء ومراقبة عملهم والإجابة على استفساراتهم من هاتفك</li>
<li>تشغيل عدة وكلاء بالتوازي عبر المشاريع ومساحات عمل Git (worktrees)</li>
<li>مراجعة الفروقات (diffs)، وتصفح سجل الـ commits، وتعديل الملفات</li>
<li>التعامل مع طلبات السحب (Pull Requests) من GitHub وGitLab وGitea وForgejo وCodeberg</li>
<li>فتح طرفية (Terminal) في أي مساحة عمل</li>
<li>إملاء التعليمات أو مناقشة المشكلات عبر الوضع الصوتي</li>
<li>جدولة تشغيل الوكلاء بشكل دوري</li>
</ul>

<b>الخصوصية</b>

لا يوجد أي قياس عن بُعد (Telemetry)، ولا تتبع، ولا حاجة لإنشاء حساب. يتصل التطبيق فقط بالخوادم التي تحددها. يمر الوصول عن بُعد عبر مُرحّل مشفر بالكامل بين الأطراف لا يمكنه قراءة بياناتك، أو عبر شبكتك الخاصة أو شبكة VPN إذا كنت تفضل ذلك.

<b>تحتاج إلى خادم daemon للاتصال به</b>

هذا التطبيق غير مفيد بمفرده. ثبّت خادم Q8iDevAI daemon على الحاسوب الذي توجد به شفرتك البرمجية وأدوات الـ CLI للوكلاء، ثم قم بإقران هذا التطبيق معه من الإعدادات (Settings). يتضمن تطبيق سطح المكتب الخادم مسبقاً، أو يمكنك تشغيله عبر npm أو Docker أو Nix.
