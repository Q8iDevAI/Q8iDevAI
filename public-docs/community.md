# Related projects

These projects are related to Q8iDevAI and built by the community.

## Plugin directory

[q8idevai.cafe](https://q8idevai.cafe) is a community-run directory of Q8iDevAI plugins. Listings are generated
from each plugin's public repository, so it is the fastest way to see what people are building and to
publish your own. It is independent of the Q8iDevAI project and nothing on it is reviewed or endorsed by
us, so read a plugin's source before installing it.

## Tools and integrations

| Project                                                                                      | What it does                                                                                                                         |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [Q8iDevAI for VS Code](https://marketplace.visualstudio.com/items?itemName=hinnes.q8idevai-vscode) | Opens the matching Q8iDevAI project or worktree in VS Code and adds agent chat, file mentions, and editor links.                        |
| [VS Code Web plugin](https://github.com/itsjustanks/q8idevai-plugin-vscode-web)                 | Opens a live Q8iDevAI worktree in `vscode.dev` through a VS Code tunnel, including workspaces on headless hosts.                        |
| [Q8iDevAI Icon](https://github.com/gpambrozio/q8idevai-menubar)                                    | Shows workspace status across Q8iDevAI hosts in the macOS menu bar and opens a workspace with one click.                                |
| [Q8iDevAI Cross-Daemon Comms](https://github.com/xpufx/q8idevai-cross-daemon-comms)                | Lets agents communicate with agents on another Q8iDevAI daemon through an MCP server.                                                   |
| [Q8iDevAI Antigravity ACP](https://github.com/tiezbro/q8idevai-agy-acp)                            | Connects Google Antigravity CLI to Q8iDevAI through ACP, with Q8iDevAI-specific context, permissions, and concurrency handling.            |
| [Desvio](https://github.com/cleiter/desvio)                                                  | Rebuilds a personal fork from a set of branches, using an agent to resolve new conflicts and Git rerere to replay known resolutions. |
